# 从零构思科研方法图

从研究中找出一次改变结果的选择。用“哪些对象经过什么操作，产生什么可检查的产物”概括机制。如果可以任意交换两个步骤而读者看不出问题，先澄清依赖关系。把节点名从“数据层/模型层”细化为研究对象，例如“街段轨迹”“候选路网”“留区误差”。给关键的边写动词，例如“聚合到”“用留出区检验”。

## 怎样主动选择构图和风格

| 论文要解释的结构 | 构图草案 | 材料与风格 |
|---|---|---|
| 输入经过一组可追踪的转换 | 连续排列同一对象的三种状态，转化步骤写在状态之间 | 技术图解。线宽统一，同一条街在三幅图保持位置；输出角落放真实结果裁片 |
| 方法分支可能产生不同判断 | 同一输入分为并行两路，在有真实判据的位置汇合；有分歧时保留两项结果 | 对照图版。中性色作结构，一种强调色标出影响选择的实测差异 |
| 全域结果掩盖局部机制 | 一幅核心地图、一个定位框和真实局部切片，方法标签贴近作用位置 | 地图集风格。保持点位和朝向，局部比例单独标明 |
| 复核或拒绝会触发返工 | 把产生工件的人/模型和评审者分放两条泳道；退回边写清触发条件并指向可重新执行的节点 | 审计图解。实线表示数据流，带标签的回边表示控制；两类边各有可追踪的端点 |

已有期刊模板或获批版式优先。无参考图时，先向用户简短说明两种有实质区别的构图和推荐理由，直接在推荐方向做效果图并继续。若科学判据或材料缺失，在草稿中把对应输出标为待验证。沿用组合图入口的生成效果图、真实证据替换、插画裁取及最终栏宽验收流程。

## 一次原创推演：街道可达性的尺度敏感性

**材料**为同一份路网、两组服务半径、同一组街道的结果表。论文想解释换半径会怎样影响街道排序。这个方法问题的关键对象是“同一街道的两条结果”。

- 草案一把“路网 → 两种半径 → 两列排名”读成方法流程。如果正文首次介绍分析方法，它能交代每个半径对应的计算。
- 草案二让两幅同范围地图并列，以街道 ID 连接右侧的配对排名图。如果正文讨论“哪些街道翻转”，它能同时展示发生地点和变化幅度。
- 若尚无结果，推荐草案一做方法图，效果图中的地图轮廓和排名框都标为占位；有底表以后绘制真实排名，查验两张地图中标注的街道是否为同一 ID。实际顺序完全相同时，如实显示重合。
- 一条可执行风格描述：“白底技术图解。把同一段路网作为两条路线的共同起点，400 m、800 m 两列纵向对齐。只在真正改变判断的街道加描边；右侧写出变化的名次，所有数字可从表中重算。”

树的父子关系和标签排布可借鉴 [D3 Tidy tree](https://observablehq.com/@d3/tidy-tree)。统计分面对齐可借鉴 [Observable Plot Facets](https://observablehq.com/plot/features/facets)。有多父节点与回路时，按真实依赖画有向图。
