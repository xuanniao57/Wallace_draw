# 从零设计空间与统计组合图

先用一句话写出读者需要完成的比较。拿到表后检查分析单元、指标单位、分母、时间窗、样本数、几何连接键和缺测。尚无数据时可以画空白尺度和构图草案，并标明待填的证据。

1. **决定哪幅图最大。** “差异在哪里”以地图为主，“差异多大”以共轴点图为主，“结论是否稳健”以估计值和区间为主。其余面板分别回答一个主图无法回答的问题。用同一观察对象测试从主图到辅图能否找到它。
2. **主动给出风格。** 根据输入，从 [视觉词汇与实例](references/visual-vocabulary.md) 选两个结构上可区分的方向，给出各一行具体的构图说明，说明哪一个更适合当前证据，按推荐方案继续。需要预览时用同一小份数据试画。已有批准稿或指定风格时直接沿用。项目已有分析后端时可以保留它，用 D3 案例指导编码。
3. **规定面板之间共享什么。** 对空间或统计组合阅读 [组图设计与验收](references/plate-design.md)。写下连接键、共享尺度、排序和局部样本的选择依据。给每个视觉通道指定一个含义。
4. **先渲染，后讲结论。** 用真实数据生成可编辑 SVG/PDF 与预览图；核对标题中每个数量能从表中重算。在目标栏宽查看图例端点、图轴、短标签和标注的落点。空间和数据结果只使用源数据渲染。

**可运行对照例。** 在本目录执行 `npm ci --ignore-scripts`、`npm run render -- <输出目录>`。例子使用 D3、TopoJSON 和美国人口普查数据，生成一个州级设色图和两个按不同指标排序的点图。源表、范围、输入文件及复现方法见 [数据说明](references/census-example.md)。新项目可复用其中的连接检查、分级和面板生成方式，换用自己的研究问题和尺度。

**用自己的配对数据作图。** 安装 pandas、numpy、matplotlib 后，从本目录运行下例。输入 CSV 每个对象一行，前后两列须同量纲；脚本输出等比例散点、等值线和配对差值的经验累积分布（SVG、PDF、PNG）。

```sh
python scripts/paired_plate.py measurements.csv --id street_id --before access_400 --after access_800 --labels "400 m" "800 m" --unit "jobs per resident" --out results
```

如有多边形边界和可比的强度指标，加 `--geo districts.gpkg --geo-id street_id --intensive --crs <本研究区投影>`（需要 GeoPandas），即可把同一批对象的差值地图并入图版。差值单位可用 `--change-unit` 指定，如百分点。输入表须先处理未配对、缺测和边界版本差异，脚本会拒绝错误连接。

若成果是方法框架或概念模型，使用 `compose-hybrid-scientific-figures` 的原创构图流程。规划用地分类、裁剪和面积汇总由 `urban-landuse-mapping` 负责。
