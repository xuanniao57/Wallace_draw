# 怎样把“高级”说成可执行的设计要求

写出五件事就足够开画：**谁和谁比、读者先看哪处、用哪个视觉通道比较、哪些尺度锁定、在哪里看例外**。下面的例子也可以用来让绘图助手自己挑风格。案例链接指向作者的实现，建议先看图，再读代码。

| 你想看清的关系 | 可以直接说的描述 | 适用条件与视觉参考 |
|---|---|---|
| 空间格局和排序是否一致 | “做成统计地图集。左侧州界设色显示增速，右侧把增速与新增人数各排前五。同一州用全名或缩写对得上。” | 面填色编码比率或密度，明确分母；总量可用位置、长度或面积成比例的符号。[D3 Choropleth](https://observablehq.com/@d3/choropleth) · [Plot Dot plot](https://observablehq.com/@observablehq/plot-dot-plot) |
| 哪种空间尺度改变了判断 | “两幅地图锁定范围和断点，在原位对照；下方只放一排区县名次变化，标出变化最大的两个。” | 有可比的地理单元，跨尺度比较先聚合到相同支持域。[Plot Facets](https://observablehq.com/plot/features/facets) |
| 哪些地区在基准两侧 | “以零为中心画残差。负值冷色，正值暖色，旁边按残差排序，共用零点；圈出连续偏高的区域。” | 明确残差符号和单位。连续同色区域只是视觉现象，显著性需另算。[D3 Diverging bar chart](https://observablehq.com/@d3/diverging-bar-chart) |
| 两个指标的关系怎样随时间改变 | “每个城市一条有方向的轨迹。标首尾年份，在转折处直标；城市多时改为同轴小多图。” | 横纵轴都是指标，连线严格按同一对象的观测时间。[D3 Connected scatterplot](https://observablehq.com/@d3/connected-scatterplot) |
| 高密度点群的主体与离群点 | “画密度等线，再覆低透明原始点，旁边列各组样本量；带宽固定，两个面板用同一坐标域。” | 等线表示点密度；浓度、温度等测量场应对测量值建模，并写清插值方法。[Plot Density](https://observablehq.com/plot/marks/density) |
| 方法中哪里发生选择 | “画左到右的研究树，每个分支端贴实际产物；保留可追溯的父子线，把选中路径加粗。” | 嵌套关系适合树；存在多父节点、汇合或反馈时用有向图并明确边类型。[D3 Tidy tree](https://observablehq.com/@d3/tidy-tree) |

## 同一份材料怎样换风格

- **地图集风格**适合读者要找地名。空间轮廓占主位，统计面板紧贴地图图例，行政边界细于主题边界。
- **统计期刊风格**适合读者要比较量级。让按效应排序的点和区间占主位，定位小图只回答样本来自哪里。区间在图注写明定义和计算方法。
- **方法图风格**适合读者要理解数据怎样变成结论。把一次分叉、验证或汇合作为视觉中心，用真实地图切片与诊断图给输入、选择和输出提供可见对象。

一句完整委托示例：“判断街道可达性差距是否随尺度改变。请先选风格，在 180 mm 双栏宽度下，用同范围地图对照 400 m 与 800 m 结果；右边按街道排序画配对点，把名次翻转的街道直接标出来。色阶和街道 ID 全图统一。”
